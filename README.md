# Orbeat Music Web

A full-stack music streaming platform built with the MERN stack, featuring separate user and artist workflows, music discovery, authentication, audio playback, and artist content management.

## Features

### User Features

- User registration and login
- JWT-based authentication
- User profile management
- Browse and search music
- Music playback with global audio player
- Like and unlike songs
- Comment on songs
- Recently played history
- Artist profile viewing
- Album and song browsing

### Artist Features

- Artist account workflow
- Artist dashboard
- Upload music
- Upload song artwork
- Create and manage albums
- Manage uploaded music
- Artist profile and content management

### Music Player

- Play and pause
- Previous and next track
- Seek/progress control
- Volume control
- Queue management
- Shuffle
- Repeat
- Current track state

## AI-Assisted Development

AI tools were used as a development aid during the development of Orbeat Music Web.

I used AI primarily for:
- Understanding unfamiliar implementation patterns and APIs
- Reviewing code and identifying potential bugs or edge cases
- Exploring alternative approaches before implementation
- Debugging runtime and integration issues
- Improving validation, error handling, and API design
- Reviewing frontend UX and responsive UI implementation
- Generating test scenarios and deployment checklists
- Refactoring repetitive code after understanding the underlying implementation

### My Development Approach

AI-generated suggestions were not blindly integrated into the project.

For each significant feature, I:
1. Defined the requirement and expected behavior.
2. Reviewed possible implementation approaches.
3. Implemented and modified the solution in the project.
4. Tested the feature locally.
5. Investigated errors and edge cases.
6. Reviewed the final code before committing it.
7. Used Git commits to track feature-level changes.

The final implementation was reviewed and adapted to the project's architecture, requirements, and coding conventions.
